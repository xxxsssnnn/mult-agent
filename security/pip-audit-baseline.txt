#           使试点不被历史欠账阻塞，同时让门禁对新增漏洞保持拦截力。

#
# 维护规则
#   1. 每完成一轮依赖升级，删除对应行，重跑门禁确认绿灯；
#   2. 新增豁免必须在 docs/SECURITY_DEBT.md 写明理由与计划版本；
#   3. 本清单只允许缩小：除"确实无修复版本"外，不允许新增条目。
